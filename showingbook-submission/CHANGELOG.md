# Changelog

## 1.0.0
Initial release.
- Viewing calendar with drag-and-drop, overlap warning, confirmation and reminder message links (SMS / email).
- Leads board with interest tags and call / WhatsApp / social links.
- Listing pipeline with drag-and-drop status changes.
- Follow-up tasks with overdue highlighting.
- Reports: leads by stage, monthly viewings, show rate, listings, top tags.
- Node/Express + SQLite (built-in node:sqlite) back end with JWT sign-in, `admin` / `agent` roles and per-user record isolation.
- Admin Team screen, change-password dialog.
- `database/schema.sql` and `database/seed.sql` (demo data).
- Installable PWA, Capacitor configuration for Android / iOS, Docker and docker-compose.
- 15 automated API tests.
